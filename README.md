# -izim

Konut binası mimari projesi (`MIMARI+PROJE_recover.dwg`) ve bu proje
üzerinden üretilen **Türk standartlarına uygun elektrik iç tesisat projesi**.

- Mimari plan: `MIMARI+PROJE_recover.dwg` (DXF dönüşümü: `elektrik/dwg/MIMARI_PROJE.dxf`)
- Elektrik tesisat planı (tipik kat, 1/50): `elektrik/cizim/ELEKTRIK_TESISAT_PLANI_TIP_KAT.dxf`
- Yük cetveli: `elektrik/hesap/YUK_CETVELI.xlsx`
- Önizleme sayfası: `elektrik/index.html`
- Üretim betikleri: `tools/`

Detaylar için `elektrik/README.md`.
